# Challenge 01: Python Calculator

This is the first project in my **100 Python Challenges** repository.

## About the Project

A simple command-line calculator written in Python. It allows users to perform basic arithmetic operations using two numbers.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Supports integers and decimal numbers
- Prevents division by zero
- Handles invalid operations

## Technologies Used

- Python 3
- Command-Line Interface (CLI)

## Requirements

- Python 3 installed on your computer

## How to Run

1. Open your terminal.
2. Navigate to the project directory.
3. Run the following command:

```bash
python3 calculator.py
```

On Windows, you can also try:

```bash
python calculator.py
```

## Example

```text
Enter your first number: 10
Enter the operation (+, -, *, /): *
Enter your second number: 5
The result is: 50.0
```

## What I Learned

- Taking user input with `input()`
- Converting input into numbers using `float()`
- Using `if`, `elif`, and `else`
- Performing arithmetic operations
- Validating the selected operation
- Preventing division by zero
