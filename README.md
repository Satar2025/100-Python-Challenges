## 📖 About the Project

**100 Python Challenges** is a hands-on learning project focused on building 100 different programs and applications using Python.

The challenges are organized into five levels, starting with basic programming concepts and gradually progressing toward more complex applications involving databases, APIs, networking, cybersecurity, automation, and artificial intelligence.

Each challenge is an opportunity to learn something new, practice writing code, and understand how programming concepts are used in real applications.

This repository is also a record of my learning journey, including completed projects, improvements, and lessons learned.

Python is a versatile programming language used in many areas of software development, including:

- Software development

- Automation and scripting
- Networking
- Cybersecurity

- Game development

Through this project, I aim to explore these areas step by step.

## 🚀 Getting Started

Follow these steps to run the projects on your computer.

### 1. Install Python

Install a compatible version of Python 3 for your operating system.

Check whether Python is installed:

```bash
python3 --version
```

On Windows, you can also try:

```bash
python --version
```

### 2. Install Git

Check whether Git is installed:

```bash
git --version
```

### 3. Clone This Repository

Replace `YOUR-USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR-USERNAME/100-Python-Challenges.git
```

### 4. Enter the Project Directory

```bash
cd 100-Python-Challenges
```

### 5. Run a Challenge

For example, to run the calculator:

```bash
python3 01-Calculator/calculator.py
```

On Windows, you can use:

```bash
python 01-Calculator/calculator.py
```

**Note:** Some projects may require additional Python packages. Their individual README files will explain how to install the necessary dependencies.

## 🧪 How Each Challenge Works

Each project will have its own documentation explaining what it does and how to use it.

Where appropriate, the individual README files will include:

1. **Project Description** — What the project does.
2. **Learning Objectives** — What I expect to learn.
3. **Features** — The main functionality.
4. **Requirements** — Required software and dependencies.
5. **Installation** — How to install dependencies.
6. **How to Run** — How to execute the program.
7. **Usage Examples** — Sample inputs and outputs.
8. **Testing** — How the program is tested.
9. **What I Learned** — Lessons from the project.
10. **Future Improvements** — Features I may add later.

Not every project will need all ten sections, but the goal is to keep the code and instructions clear.

## 🗺️ Learning Roadmap

The project follows a gradual learning path.

### Phase 1: Python Fundamentals

Learn variables, data types, operators, conditions, loops, functions, and basic algorithms.

### Phase 2: Data Structures and Problem Solving

Practice lists, dictionaries, strings, searching, sorting, and reusable functions.

### Phase 3: Files and Databases

Learn file handling, JSON, CSV, SQLite, and data persistence.

### Phase 4: Application Development

Build graphical applications, games, bots, web tools, and automation scripts.

### Phase 5: Networking and Cybersecurity

Explore network programming, traffic analysis, file integrity, logging, and security testing in authorized environments.

### Phase 6: Advanced Development

Build web APIs, database-driven applications, machine learning models, and a complete final project.

This roadmap is flexible. Some topics may require additional study before their associated challenges can be completed.

## 🔐 Security and Responsible Use

Some challenges involve networking, passwords, web applications, and cybersecurity.

All security-related projects are intended for educational purposes and authorized testing only.

- Test network tools only on systems you own or have permission to assess.
- Do not publish passwords, API keys, access tokens, or other secrets.
- Use appropriate security practices when handling user information.
- Treat security testing as a way to improve protection, not to harm others.
